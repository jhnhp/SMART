PYTHON Versi Python Terstandar
Python 3.10 atau 3.11 (64-bit)
Pustaka biner (wheels) rasterio dan quantile-forest tersedia resmi tanpa butuh compiler C++ di Windows. Hindari Python 3.13 untuk meminimalkan isu kompilasi.
GIS & VENV QGIS Desktop & Virtual Env
QGIS 3.28 s.d. 3.34+ LTR & env_smart
Gunakan virtual environment terisolasi via skrip satu-klik setup_env.sh (Linux/Mac) atau setup_env.bat (Windows) agar pustaka tidak bentrok dengan Python sistem.
CLOUD Dukungan Google Colab
Solusi Peserta Spek Terbatas
Seluruh notebook dilengkapi pendeteksi otomatis if 'google.colab' in sys. Peserta dengan laptop RAM terbatas dapat langsung menjalankannya via Google Colab (12 GB RAM gratis).
