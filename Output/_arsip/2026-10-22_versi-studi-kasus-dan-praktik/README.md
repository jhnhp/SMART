# Arsip: versi Modul 1–3 dengan studi kasus dan praktik (22 Oktober 2026)

Folder ini menyimpan versi Modul 1–3 sebelum arah proyek diubah pada 26 Oktober 2026. Sejak tanggal itu, modul berfokus pada teori, strukturnya identik dengan Bab 1–2, dan tidak memuat studi kasus Sub-DAS Bompon maupun praktik (lihat `CLAUDE.md`).

Versi di sini masih memuat bagian yang kini tidak dipakai:
- Tujuan dan Capaian Pembelajaran;
- Rangkuman;
- praktik dengan data Sub-DAS Bompon;
- uraian dan gambar studi kasus Bompon;
- subbab tambahan dari silabus;
- daftar pustaka per modul.

Bagian-bagian tersebut dapat dipakai kembali ketika studi kasus dan praktik ditambahkan.

## Isi
- `Modul 1.md`, `Modul 2.md`, `Modul 3.md`: naskah versi lama. Tautan gambarnya merujuk ke `assets/` di folder ini.
- `assets/`: semua gambar versi lama, termasuk peta lokasi Bompon, lapisan data Bompon, potongan foto udara, serta analisis tumpang susun dan generalisasi.
- `scripts/`: skrip versi lama, termasuk `analisis_modul_3.py` untuk analisis tumpang susun Bompon (keluarannya tersimpan di `assets/modul-3/statistik_modul_3.json`).

Skrip di folder ini disimpan sebagai rekam jejak. Jika ingin dijalankan kembali, salin dulu ke `Output/scripts/`, karena jalur relatifnya mengacu pada lokasi tersebut.
